# Spot publicitaire AccessQ — 45 secondes

- Format : 1920 × 1080, paysage 16:9, 24 images/seconde
- Langue : français
- Positionnement : organisateurs de mariages, conférences, concerts et cérémonies
- Promesse : « Un QR. Une règle. Une décision immédiate. »
- Appel à l’action : « Créez votre événement gratuitement »

## Génération

Depuis la racine du projet :

```bash
bash marketing/video-accessq-45s/generate-video.sh
```

Le fichier final est généré sous `marketing/video-accessq-45s/accessq-publicite-45s-1080p.mp4`.

La vidéo fonctionne sans narration grâce aux textes à l’écran. Le fichier `voix-off.txt` contient la narration chronométrée si une voix humaine doit être ajoutée ensuite.
